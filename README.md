# 小小单词卡 · Metalio Wordcard

运行在无名 **Metalio E-INK4 Plus（ESP32-S31、4.7 英寸前光墨水屏）** 上的离线英语单词机。

以分级背词为主线，也可以把自己书上、工作中遇到的英文整理成词表导入，在设备上查词、听发音、练词义和拼写、复习自己的单词。

## 当前可以做什么

- **分级背词**：入门、日常核心、通用进阶；高阶内容仍在完善，不能把试学样本当完整雅思词库。
- **分轮练习**：先认识一组词，再检查词义；可选补字母后全拼、直接全拼或只练词义。
- **独立复习**：词义、拼写分别记录 FSRS-6 状态；错词隔开再检查，一次答对不直接算长期掌握。
- **自己的单词表**：只需英文，一行一个词或短语，匹配离线词典的释义、音标；确认后加入个人单词本。
- **离线发音**：优先 SD 音频，缺失时用 Amy Small FP32，缓存后可直接再听，失败时由 eSpeak-NG 托底。
- **设备功能**：前光、音量、USB SD 传输、时间设置、关机单词卡；旧课程保留在“更多学习”。

这是持续迭代的爱好者项目。墨水屏刷新有延迟，TTS 首次生成仍有等待；词库内容、外部资源和语音模型与固件版本需要配套。等级与掌握量是学习辅助信息，不是正式英语能力认证。

## 仓库包含什么

`firmware/` 是可编译的 S31 固件及必要的适配代码；`src/legacy-course/` 是旧课程兼容模块的生成输入；`tools/` 包含生成器与诊断工具；`tests/` 包含主机检查。

为保证直接构建，保留了必要的生成 C/C++ 文件（内置兼容词表、课程数据、屏幕波形和关机插画）。大容量 SD 词库、音频、模型和字库单独分发。开发缓存、个人进度、生词本、照片、设备备份和测试运行数据均不在仓库中。
