# 导入自己的英文词表

设备安装配套离线词典后，只需准备英文，释义、音标和发音通过现有词典与语音流程匹配。可先试 [示例 my-words.txt](../examples/my-words.txt)。

1. 将文件保存为 **UTF-8 的 `my-words.txt`**，一行一个英文单词或短语；不要带序号、中文释义或表格。
2. 在设备设置中进入 U 盘模式，把文件放到 **SD 卡的 `metalio/e-ink/wordcards/` 目录**。注意 Windows 隐藏扩展名时，不要保存成 `my-words.txt.txt`。
3. 安全弹出 U 盘，回到学习，进入“我的单词本”中的词表导入入口，点“读取单词表”。
4. 检查匹配结果，再点“加入我的单词本”。重新导入相同词不会重复累计；原有单词和学习记录保留。
5. 从单词本开始学习；听发音、词义、拼写和到期复习沿用现有流程。

```text
appointment
available
look after
firmware
software
API
```

没有匹配的词需要检查拼写或补充词典，不能把“文件读取成功”当成每个词都有完整资料。来源照片可以先交给 AI 整理为以上纯文本格式；照片本身不直接导入设备。导入后查词失败或无法保存时，保留原文件和记录，运行诊断工具；不要反复重置进度。
