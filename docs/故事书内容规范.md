# S31 故事书内容规范

适用于固件 `fix62b-story-memory` 和 `schema: 3` 的故事包。

## 按学习目的选类型

| 书架类型 | 一本书的主活动 | 现有书目 |
| --- | --- | --- |
| 分段学词 `vocabulary` | 读一小段，练四个词，后续段落穿插回忆 | 《口袋里的收据》《石头汤》《错站台的票》 |
| 阅读理解 `comprehension` | 按幕读正文，答本幕的理解题，回原文核对依据 | 《二十年后》 |
| 任务冒险 `adventure` | 接委托，用词完成现场任务，收集证物，推进到下一章或结局 | 《末班书船》《雨夜失物处》 |

每本书声明一个主类型。原画、译文、发音和剧情分支是可选的内容。新作者沿用相应类型的章节结构和播放器。一本新书的书名、编号和题目只出现在书包数据中。

## 三类书共用的字段

每个版本放在 `packs/<id>/<version>/`。目录下有 `manifest.json`、`content.json` 及清单列出的媒体文件。已发布的版本不可覆盖，修改后递增版本号。

| 字段 | 约定 |
| --- | --- |
| `format`、`type`、`schema` | 分别为 `wordcard-pack`、`story` 和整数 `3` |
| `storyType` | 上表中的一个英文类型值 |
| `id`、`title`、`version` | 稳定的包编号、书架上的书名、三段式版本号 |
| `requires` | 精确的词库编号和版本。本次六本书使用 `pet-2024@1.0.0` |
| `files` | 内容文件名及其 SHA-256。打包工具重新计算并校验 |
| `content.json` | 共同包含简介 `intro` 和按顺序排列的 `chapters`，每章有 `title` |

书架在书名旁标出类型，同编号优先展示最新标准版。缺依赖时指出需要安装的词库。返回内容库能回到原分类，从首页继续能回到原书。章节进度按书和版本保存；共享的词义和复习日期仍由原生学习系统管理。

## 分段学词

每章有 `title`、`en`、`zh` 和 `words`。双语正文描述一个场景。英文原句用 `[[term]]` 标记本段四个目标词，题目顺序由 `words` 决定。每个目标词在全书只首次引入一次。

```json
{
  "term": "concert",
  "gloss": "音乐会",
  "distractors": ["排练", "乐队", "演讲"]
}
```

在书级 `terms` 里为 `concert` 提供词库条目编号和带词性的场景释义。题面短释义可更口语化。三个干扰项要与正确义项有区别，且在这个场景中只有一个合理答案。

每段两词先自己回忆，再看四个中文选项，另外两词直接选择。在下一段穿插上段词，末段收尾再问。答错或选择“想不起来”会给出词义和本段原句。在同一个词的两次提问之间，至少插入三个不同的其他词；仍然答错的订正题可在书末继续。若提供 `album`，可在封面、读段或书末翻看原绘本和译文，回到学习时保留位置。

## 阅读理解

每章的 `pages` 是按阅读顺序排列的双语正文。一道 `questions` 题包含英文题干 `en`、中文题干 `zh`、二至四个不同的 `options`、正确选项下标 `answer`、解释 `reason` 和原文依据页下标 `evidence`。下标从零开始。正文可用 `[[term]]` 标注随文词义。

读完一幕直接答理解题，可以从题面返回依据页，再回到同一题。理解题记录本次选择，全书结束时汇总。翻页、看译文、查随文词义和答剧情题均不会给单词增加一次正式评分。

## 任务冒险

每章填写 `title`、`topic`、委托开场 `intro`、证物 `token`、章末进展 `outro` 和 `words`。每个现场词引用已声明词库中的编号，提供留有一个 `[ ]` 的英文句和中文句。章节可声明分支引言和来自前章的回访词。幕次 `acts`、证物关 `gates`、选择 `forks` 和结局都由数据指定。短篇可以直接写一个结局。

现场词题把词义和技能评分交给共用词汇引擎。委托进展、证物、分支选择和结局由本书保存。词义的共享条件沿用学习系统的判定，包含拼写和场景释义核对。

## 写书和验收

六本正式内容位于项目的 `resources/stories/`。各取一本同类型的书作样本即可。运行下面的入口生成内容包和校验章节、选项、词义标注及配图。

```powershell
.\tools\pack-content.ps1 -SourceDirectory .\resources\stories\stone-soup\1.1.0 -OutputFile .\work\stone-soup-1.1.0.zip
.\tools\test-story-reader.ps1
```

回归覆盖书架上的类型、并存版本、打开和返回、双语与图片、全部分段词的两次提问、至少三个不同词的间隔、错答续读、理解题的证据页，以及故事到 PET 复习再返回后的日期。2026 年 11 月 23 日已在 S31 上刷入固件并读回校验。实机逐本打开了六本书，并通过可见控件的触区走完《口袋里的收据》《二十年后》和《雨夜失物处》。
